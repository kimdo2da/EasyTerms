# EasyTerms
보험 약관, 대출 약관, 임대차 계약서, 구독 서비스 약관 등은 전문 용어와 복잡한 문장으로 작성되어 있어 일반 사용자가 내용을 이해하기 어려운 경우가 많다.

특히 사용자는 계약서를 읽더라도 **계약 기간, 발생 비용, 중도해지 조건, 위약금, 자동갱신 여부 등 실제로 중요한 내용을 직접 찾아야 하며**, 생소한 법률·금융 용어 때문에 내용을 잘못 이해할 수도 있다.

EasyTerms는 이러한 문제를 해결하기 위해 사용자가 약관이나 계약서를 텍스트 또는 문서 파일로 입력하면 생성형 AI가 문서의 내용을 분석하여 **쉬운 설명, 핵심 조건, 확인해야 할 내용, 어려운 용어 설명 등을 제공하는 웹 서비스**이다.
